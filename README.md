# Python untuk Pemula
Repositori latihan dari kursus Santrikoding oleh Dila.

## Materi
Variabel, operator, kondisi, perulangan, list dan dictionary, fungsi, class, pip dan virtual environment.

## Cara menjalankan
1. `python -m venv venv` lalu aktifkan dengan `source venv/bin/activate`
2. `pip install -r requirements.txt`
3. `python nama_file.py`
